# October 2023 version of the pooled human TCR-epitope database

This folder contains the October 2023 update of the curated human TCR-epitope pooled database, generated with the same curation pipeline as the March 2023 version (see `Data/Database/`). Source databases were downloaded in October 2023, with the exception of McPAS-TCR (see below).

## Files

- `database_pooled_human_2023_10_17.txt` — pooled curated database (October 17, 2023)
- `IEDB_tcell_assay_table_MHCII.csv` — IEDB MHC class II assays (October 2023)
- `IEDB_tcell_receptor_table_MHCI.csv` — IEDB MHC class I receptors (October 2023)
- `IEDB_tcell_receptor_table_MHCII.csv` — IEDB MHC class II receptors (October 2023)
- `McPAS-TCR.csv` — McPAS-TCR database. **Identical to the March 2023 version** (`Data/Database/McPAS-TCR.csv`): McPAS-TCR was not updated between March and October 2023. Kept here for completeness.
- `vdjdb.txt` — VDJdb database (October 2023)

## File hosted on Zenodo (not in this repository)

- `IEDB_tcell_assay_table_MHCI.csv` (195 MB, October 2023) exceeds GitHub's file size limit and is therefore not included here. It is archived as a supplementary file on Zenodo with this release: https://doi.org/10.5281/zenodo.20402420
